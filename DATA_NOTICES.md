# Data and appearance notices

The bundled reference consists only of MAIForge-generated numeric endpoint
fields and allowlisted provenance metadata. It contains no third-party game
models, texture packs, private filesystem paths or source-session records.
The field files are offered under AGPL-3.0-only for this release; scientific
references and upstream software retain their own rights.

The historical endpoint is identified by hashes in its manifest. It is not a
new validation of the scientific model or a promise of exact regeneration with
the current core. Climate colours and rock grain are generated appearance
priors. Consult the core DATA_NOTICES.md for scientific parameter provenance.
